## ダウンロード

> **初めて利用する方、どれを選べばよいか迷った方は、`KSO_Pilot_0.5.0_Distribution.zip`をダウンロードしてください。**

| ファイル | 内容 |
| --- | --- |
| `KSO_Pilot_0.5.0_Distribution.zip` | 推奨。インストーラー、インストール手順書、操作ガイド、変更履歴をまとめた配布パッケージです。 |
| `KSO_Pilot_0.5.0_x64-setup.exe` | Windows 64ビット版のインストーラー単体です。手順書をすでにお持ちの方向けです。 |
| `KSO_Pilot_0.5.0_x64-setup.exe.sha256` | インストーラーが正しくダウンロードされたか確認するためのSHA-256値です。 |
| `KSO_Operation_Guide_Pilot_0.5.0.zip` | 操作ガイドのみをまとめたファイルです。 |

パイロット版は正式版に向けた検証中のリリースです。配信本番で使用する前に、使用するPC、OBS設定、セットリストで動作を確認してください。

## Microsoft Defender SmartScreenが表示された場合

KSOパイロット版は現在コード署名されていないため、正しい配布ファイルでもWindowsの「このアプリは認識されませんでした」という警告が表示されることがあります。この警告が表示されてもインストールは可能です。

このGitHub Releaseから入手したファイルであり、ファイル名とSHA-256が同梱の`.sha256`ファイルと一致することを確認した後、SmartScreen画面の「詳細情報」を選択し、続いて「実行」を選択してください。配布元を確認できない場合やSHA-256が一致しない場合は実行しないでください。

## 変更履歴

- 更新日: 2026年8月30日
- 比較元: KSO パイロット版 0.4.0（Gitタグ `v0.4.0`、コミット `3398337`）
- 対象インストーラー: `KSO_Pilot_0.5.0_x64-setup.exe`

### 追加

- 再利用する曲情報を登録・検索・編集できる「マイソング」を追加しました。
- マイソングのJSON保存先を利用者が選べるようにしました。新規作成、既存ファイル選択、保存先変更に対応しています。
- 曲名、アーティスト、YouTube URL／動画ID、LRC原本、歌詞オフセット、タグ、お気に入り、歌唱キー、メモを保存できます。
- 実際に歌唱完了した順序をマイソングJSONへ保存し、歌唱回数と最終歌唱日を自動更新するようにしました。
- 歌唱結果をMarkdown／CSVへ保存できるようにしました。配信開始時刻を入力すると、MarkdownへYouTubeチャプター用一覧を追加します。

### 変更

- セットリストタブを「マイソング」と「セットリスト作成」の2画面へ整理しました。
- マイソングから1曲または複数曲をセットリストへ追加でき、セットリストへ直接入力した曲もマイソングへ登録できるようにしました。
- セットリスト形式をv2へ更新し、曲ごとのアーティストとマイソングIDを保存するようにしました。
- 曲カードのドラッグ＆ドロップに加え、従来の「↑」「↓」でも曲順を変更できます。
- 既存セットリストを「複製して新規保存」で次回用に再利用できるようにしました。
- 「直前の完了を取り消す」と、セッション表示だけでなくマイソングJSONの履歴と集計も戻るようにしました。

### LRC原本と安全性

- マイソングJSONにはLRC本文を取り込まず、利用者が管理するLRC原本のパスを保存します。
- セットリスト保存時はLRCをセットリスト配下へコピーするため、フォルダー単位で持ち運べる従来の構成を維持しています。
- LRC原本が移動または削除されている場合は、マイソングでの再指定を案内します。
- セットリスト内で編集したLRCを原本へ戻す操作は確認付きの「LRCを原本へ反映」に限定し、意図しない上書きを防ぎます。
- マイソングJSONは一時ファイルへ書き込んでから置換し、保存途中の破損を避けます。

### 互換性

- 0.4.0以前のセットリストv1は移行操作なしで読み込めます。未登録のアーティストは空欄として扱います。
- v1セットリストの再生、LRC、歌詞オフセットは維持されます。次回保存時にv2形式になります。
- 0.4.0以前に保存したテーマ、配信操作ショートカット、OBS接続情報、OBSブラウザソース設定プロファイルを引き続き利用できます。
- マイソングと歌唱履歴はローカルJSONで管理し、クラウド同期や公開用曲リストは含みません。

### 確認項目

- マイソング保存先の新規作成、再選択、変更
- 登録、編集、検索、お気に入り絞り込み、双方向のセットリスト連携
- セットリストv1互換、v2保存、ドラッグ／ボタン並べ替え、複製
- LRC原本欠落時の案内と明示的な原本反映
- 歌唱完了、取り消し、歌唱集計、Markdown／CSV／YouTubeチャプター出力
- Core、Rust、全パッケージビルド、Playwrightビジュアル回帰試験
- Windows向け0.5.0インストーラーの上書きインストールと実画面表示
- OBS WebSocket実接続と既存ブラウザソース状態確認

### 操作手順

詳しい使い方は、同梱の「KSO 操作手順書 パイロット版」を参照してください。マイソングの保存先と曲登録は「セットリスト」→「マイソング」、歌唱結果の出力は「カラオケ」→「セットリスト」モードから操作します。
