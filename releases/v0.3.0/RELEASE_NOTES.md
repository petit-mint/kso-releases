# KSO パイロット版 0.3.0 変更履歴

- 更新日: 2026年8月22日
- 比較元: KSO パイロット版 0.2.0（Gitタグ `v0.2.0`、コミット `c474197`）
- 対象予定インストーラー: `KSO_Pilot_0.3.0_x64-setup.exe`

## 追加

- セットリスト再生中の現在曲と、そのKSOセッションで歌唱完了した曲を表示する専用OBSブラウザソースを追加しました。
- 曲情報OBSソースのURLとして `http://127.0.0.1:17171/song-info` を追加しました。
- 現在曲がない場合はNOWパネル、歌唱履歴がない場合はSETLISTパネルを自動的に隠すようにしました。
- 現在曲を明示的に歌唱完了へ追加する操作と、直前の完了を取り消す操作を追加しました。
- 動画の自然終了時に現在曲を自動で歌唱完了にする設定を追加しました。
- 既存のOBSスタイルエディタへ「歌詞」「曲情報」の切り替えを追加しました。
- 曲情報の配置、余白、パネル幅、背景、角丸、影、見出し、現在曲、歌唱履歴、アニメーションをCSSなしで設定できるようにしました。
- 曲情報向けに「標準」「コンパクト」「シンプル」のスタイルプリセットを追加しました。
- 実際の曲情報HTMLを使うリアルタイムプレビューと、曲情報専用の詳細CSS設定を追加しました。
- 曲情報OBSソースの作成、状態比較、OBS側で調整したサイズとCSSの取り込みに対応しました。
- セットリスト編集からYouTube検索画面を開き、選んだ動画を対象トラックへ取り込む機能を追加しました。
- KSO内でYouTube検索画面を開けない場合、同じ検索語を外部ブラウザで開くフォールバックを追加しました。
- KSOが背面にあるときも利用できる配信操作用グローバルショートカットを追加しました。
- 再生／一時停止、停止、前後の曲、歌唱完了、完了取り消し、歌詞タイミング±100msの8操作を割り当てられるようにしました。

## 変更

- OBSブラウザソース設定プロファイルで、歌詞ソースと曲情報ソースを一組として管理するようにしました。
- OBSへの反映画面で、歌詞ソースと曲情報ソースそれぞれのURL、サイズ、カスタムCSSを確認できるようにしました。
- OBS側の調整結果は、プロファイル編集欄で選択中の「歌詞」または「曲情報」へ取り込むようにしました。
- YouTube選択画面のトップレベル遷移先を必要なYouTubeドメインへ制限し、KSOのローカルIPC権限を公開しない構成にしました。
- KSOを単一起動にし、二重起動時は既存のメイン画面を前面へ表示するようにしました。
- メイン画面を閉じた場合、YouTube選択画面、動画音声、オーバーレイサーバー、OBS処理を含むKSO全体を終了するようにしました。
- オーバーレイ用ポートを起動時に確保できない場合、不完全なKSOプロセスを残さず起動を中止するようにしました。
- グローバルショートカットは初期状態で無効とし、設定画面から有効化、割り当て変更、個別解除、初期化を行う方式にしました。

## 互換性

- 0.2.0以前に保存したOBSブラウザソース設定プロファイルは引き続き利用できます。
- 既存プロファイルには曲情報の標準設定を自動補完します。
- 既存の歌詞用カスタムCSSとオーバーレイスタイル設定は変更せず保持します。
- LRCおよびセットリストのファイル形式に変更はありません。
- 曲情報の歌唱履歴はKSOの実行中だけ保持し、保存済みセットリスト自体は変更しません。

## 確認済み項目

- フロントエンド、共有パッケージ、Coreパッケージの本番ビルド
- Rustユニットテスト13件
- 曲情報スタイル設定と実HTMLプレビュー
- グローバルショートカット8操作、重複時の部分登録、無効化、再起動時の自動登録
- OBSを前面にした状態での歌詞タイミングショートカット
- 通常終了後のKSOプロセスとオーバーレイ用ポートの解放
- Windows配布版のインストールと、情報画面のバージョン`0.3.0`表示
- 配布版WebView2でのYouTube検索、SPA動画ページ遷移、動画再生、URL取り込み
- 動画再生中の取り込み後にYouTube選択画面と動画音声が残らないこと
- YouTube選択画面だけを閉じた場合にKSO本体が動作を継続すること
- YouTubeページ上の外部リンク操作で追加ウィンドウが生成されないこと
- YouTube用WebViewをcapability対象外とし、リモートURLへIPC権限を公開しない構成
- 二重起動時の後発プロセス終了と、既存メイン画面の継続動作
- インストーラー、SHA-256、操作手順書ZIP、配布ZIPの生成と整合性

## 操作手順

詳細は同梱の「KSO 操作手順書 パイロット版」を参照してください。曲情報の見た目設定は「OBSブラウザソース設定プロファイル」と「8.14 曲情報の見た目を変更する」、配信操作用ショートカットは「8.15 配信操作用ショートカットを設定する」に記載しています。
