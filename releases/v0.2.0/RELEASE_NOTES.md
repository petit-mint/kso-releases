# KSO パイロット版 0.2.0 変更履歴

- リリース日: 2026年8月15日
- 比較元: KSO パイロット版 0.1.0（Gitコミット `fd5c8f7`）
- 対象インストーラー: `KSO_Pilot_0.2.0_x64-setup.exe`

## 追加

- OBSブラウザソース設定プロファイルへ「オーバーレイスタイルエディター」を追加しました。
- 前・現在・次の歌詞ごとに、文字色、文字サイズ、太さ、フォントを選べる「かんたん設定」を追加しました。
- OBSと同じオーバーレイHTMLを使うリアルタイムプレビューを追加しました。
- プレビュー背景を、市松模様、暗い背景、明るい背景へ切り替えられるようにしました。
- 「カスタムCSS（詳細設定）」を追加し、利用可能なセレクターと記述例をCSSコメントで案内するようにしました。
- かんたん設定へ、表示位置、余白、歌詞同士の間隔、文字の不透明度、行の高さを追加しました。
- 前・現在・次の歌詞ごとに、背景色と透明度、背景余白、角丸、文字の縁取り、影を設定できるようにしました。
- 歌詞切替時のフェード、スライド、ズームと、アニメーション時間の設定を追加しました。
- 標準、縁取り強調、字幕帯、バラード、アップテンポのスタイルプリセットを追加しました。

## 変更

- オーバーレイCSSを「標準CSS → かんたん設定から生成したCSS → 詳細設定のカスタムCSS」の3層で適用するようにしました。
- 既存プロファイルのカスタムCSSを保持したまま、詳細CSSガイドを自動追加するようにしました。
- OBS側の設定をKSOへ取り込む場合、OBSのCSSをそのまま保持するため、かんたん設定から独立した詳細CSSとして保存するようにしました。
- リリース版KSOの起動時に表示される専用コマンドプロンプトを最小化するようにしました。既存のコマンドプロンプトから起動した場合、その親画面は最小化しません。
- カスタムCSSのガイドへ、配置、余白、文字、背景、縁取り、影、歌詞切替アニメーションの具体的な記述例を追加しました。
- 設定画面をスクロールしても、右側のオーバーレイプレビューが画面上部へ追従するようにしました。狭い画面では従来どおり縦並びで表示します。

## 互換性

- 0.1.0で保存したOBSブラウザソース設定プロファイルは引き続き利用できます。
- 以前の0.2.0で保存したオーバーレイ設定は、新しい設定項目の初期値を補完して読み込みます。
- 既存のカスタムCSSは削除されません。
- LRCおよびセットリストのファイル形式に変更はありません。

## 操作手順

詳細は同梱の「KSO 操作手順書 パイロット版」の「OBSブラウザソース設定プロファイル」と「設定タブ内の各機能の操作手順」を参照してください。
