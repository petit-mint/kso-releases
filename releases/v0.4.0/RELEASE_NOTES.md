# KSO パイロット版 0.4.0 変更履歴

- 更新日: 2026年8月26日
- 比較元: KSO パイロット版 0.3.0（Gitタグ `v0.3.0`、コミット `2ae2d14`）
- 対象インストーラー: `KSO_Pilot_0.4.0_x64-setup.exe`

## 追加

- メインメニューへ「セットリスト」タブを追加しました。
- 設定画面へ「基本設定」「配信操作」「OBS接続」「表示デザイン」のカテゴリーナビゲーションを追加しました。
- OBS接続と表示デザインの間に「表示デザインを編集」「OBSへ反映」の相互導線を追加しました。

## 変更

- セットリスト作成を設定画面から独立させ、メインメニューから直接開けるようにしました。
- 広い画面では設定カテゴリーを左側に、狭い画面では上部に表示するレスポンシブ構成へ変更しました。
- 設定画面では選択したカテゴリーだけを表示し、長い設定フォームが同時に並ばないようにしました。
- OBSブラウザソース設定プロファイルとスタイル編集を「表示デザイン」へ、OBS WebSocket接続とソース反映を「OBS接続」へ整理しました。
- セットリストの未保存確認とLRC編集後の戻り先を、独立したセットリストタブに合わせて変更しました。

## 互換性

- 0.3.0以前に保存したテーマ、配信操作ショートカット、OBS接続情報、OBSブラウザソース設定プロファイルを引き続き利用できます。
- LRCおよびセットリストのファイル形式に変更はありません。
- 保存済みセットリストは移行操作なしで開けます。
- OBS WebSocket、オーバーレイサーバー、YouTube再生、LRC編集の機能仕様に変更はありません。

## 確認項目

- 設定カテゴリー切替後もOBS WebSocketホスト入力が保持されること
- 広幅と狭幅で設定カテゴリーナビゲーションが正しく切り替わること
- セットリスト作成をメインメニューから直接開けること
- セットリストの長い入力内容が狭い画面でも操作できること
- Core、Rust、全パッケージビルド、Playwrightビジュアル回帰試験
- Windows向け0.4.0インストーラーの上書きインストールと実画面表示

## 操作手順

詳しい使い方は、同梱の「KSO 操作手順書 パイロット版」を参照してください。セットリストはメインメニューの「セットリスト」、OBSの接続と反映は設定の「OBS接続」、歌詞と曲情報の見た目は設定の「表示デザイン」から操作します。
