> **初めて利用する方、どれを選べばよいか迷った方は、`KSO_Pilot_0.6.0_Distribution.zip`をダウンロードしてください。**

| ファイル | 内容 |
| --- | --- |
| `KSO_Pilot_0.6.0_Distribution.zip` | 推奨。インストーラー、インストール手順書、操作ガイド、変更履歴をまとめた配布パッケージです。 |
| `KSO_Pilot_0.6.0_x64-setup.exe` | Windows 64ビット版のインストーラー単体です。手順書をすでにお持ちの方向けです。 |

## 変更履歴

- 更新日: 2026-09-05
- 比較元: KSO パイロット版 0.5.0
- 対象インストーラー: `KSO_Pilot_0.6.0_x64-setup.exe`

### 変更内容

- セットリストv3を導入し、新規保存する曲のLRCを任意にしました。LRC必須の既存v1／v2は移行操作なしで読み込めます。
- マイソングv3を導入し、LRCがまだないリクエスト曲、歌唱履歴、配信履歴を同じJSONで管理できるようにしました。既存v1／v2はそのまま読み込み、次回保存時にv3へ更新します。
- 単曲とセットリストを同じ配信セッションへまとめ、実際に歌唱完了した順序を自動保存できるようにしました。
- 未登録の飛び入りリクエストをLRCなしで歌い、必要な場合だけマイソングへ登録できる曲情報欄を追加しました。
- 配信セッションと曲開始時刻をミリ秒で自動保存し、`0:00 オープニング`から始まるYouTubeチャプター用一覧をコピーできるようにしました。配信開始・終了後の補正、過去配信の再編集、YouTube条件の警告にも対応しています。
- 短い誤再生後のやり直し判定を追加し、最大再生時間と先頭位置を設定できるようにしました。一時停止からの再開では曲開始時刻を更新しません。
- 配信中にマイソングを切り替えた場合、個別の歌唱履歴は切り替え前後の各JSONへ、配信全体は配信開始時のJSONへ保存します。
- 現在曲と歌唱済み曲のOBS表示を配信セッション単位へ統一しました。

### 確認内容

- TypeScriptビルド、Rustチェック／単体テスト、Playwrightビジュアル回帰を実施しました。
- LRCなしのマイソング登録、マイソングv3移行、セットリストv3の保存・再読込・再生、単曲リクエストの歌唱完了、セッション復元、誤再生後のやり直し、マイソング切り替え、過去配信の再編集と削除、履歴出力を自動シナリオで確認しました。
- Windowsリリースビルド、OBS実接続、上書きインストールはリリース候補作成時に手動確認します。
